💡 상세 설명 가능 항목

10. MAC 연산 로직 설명

전체 흐름:
def mac_operation(pattern, filter_matrix): score = 0.0 # 1. 점수 초기화 n = len(pattern) # 2. 패턴 크기 확인 for i in range(n): # 3. 행 순회 for j in range(n): # 4. 열 순회 # 5. 위치별 곱셈 (Multiply) # 6. 누적 합산 (Accumulate) score += pattern[i][j] * filter_matrix[i][j] return score # 7. 최종 점수 반환

11. 패턴 크기 추출 로직

설계: 패턴 키에서 크기 N 자동 추출
예시: "size_5_1" → size=5 → filters["size_5"] 선택
역순 확인: size_25 → size_13 → size_5 (긴 문자 우선)

12. 라벨 정규화 분리 이유

✓
재사용성: 모드 1, 모드 2 모두 사용
✓
유지보수: 새 라벨 추가 시 한 곳만 수정
✓
테스트: 개별 함수 단위 검증 가능

13. 시간 측정 경계

측정 범위:
start = time.time() mac_operation(pattern, filter) # ← 순수 연산만 측정 end = time.time() (end - start) * 1000 # 초 → ms 변환

14. MAC 점수 ↔ 유사도 관계

원리: 위치별 곱셈 후 누적
같은 패턴 × 같은 필터 = 최대 값
다른 패턴 × 필터 = 더 낮은 값
결론: 점수가 높을수록 유사도 높음

15-16. O(N²) 복잡도와 부동소수점

크기 연산 수 시간 N 대비
N=5 25 ~0.001ms 기준
N=10 100 ~0.004ms 4배
N=20 400 ~0.016ms 16배
